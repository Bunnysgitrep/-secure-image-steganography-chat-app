🔐 Secure Steganography Process

This system hides encrypted messages inside images using LSB (Least Significant Bit) steganography.

Step 1: Encryption

  • Your secret message is encrypted using a password.
  • Encryption uses SHA-256 key generation and Fernet symmetric encryption.
  • This ensures only the correct password can decrypt the message.

Step 2: Hiding Inside Image

  • The encrypted message is converted into binary.
  • Each bit is stored in the least significant bit of image pixels.
  • This does not visibly change the image appearance.

Step 3: Extraction

  • The system reads the least significant bits from the image.
  • The binary data is reconstructed.
  • The message is decrypted using the correct password.

Security Features

  • Strong password validation (uppercase, lowercase, number, special character).
  • 3 failed attempts limit.
  • 24-hour block after multiple failed attempts.
  • End-of-data delimiter protection.

Without the correct password, the hidden message cannot be decrypted.
