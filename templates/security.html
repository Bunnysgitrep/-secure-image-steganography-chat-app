🔐 Core Security Technologies Used

1️⃣ SHA-256 Key Derivation

The password is converted into a secure cryptographic key using SHA-256 hashing. This ensures that the original password is never stored directly.

2️⃣ Fernet Symmetric Encryption

The system uses Fernet encryption (based on AES). It provides:

  • Confidentiality
  • Integrity verification
  • Authenticated encryption

3️⃣ LSB (Least Significant Bit) Steganography

The encrypted message is hidden inside the image by modifying the least significant bits of pixel values. This keeps the image visually unchanged.

4️⃣ Password Policy Enforcement

  • Minimum 12 characters
  • At least one uppercase letter
  • At least one lowercase letter
  • At least one number
  • At least one special character

5️⃣ Brute Force Protection

  • Maximum 3 failed attempts
  • Automatic 24-hour block after limit
  • IP-based tracking of attempts

6️⃣ Data Delimiter Protection

A special binary delimiter is used to mark the end of hidden data, ensuring accurate extraction.

7️⃣ Secure Transmission (Local API)

The frontend communicates securely with the backend using controlled API endpoints.

🔒 Without the correct password, the hidden message cannot be recovered.
